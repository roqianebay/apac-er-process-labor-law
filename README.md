## Local preview

```powershell
cd web
python -m http.server 8765
```

Open http://127.0.0.1:8765/

## Publish updates

Edit files under `web/`, then:

```powershell
git add web/
git commit -m "Update site content"
git push
```

Pushing to `main` runs **Deploy GitHub Pages** automatically.
